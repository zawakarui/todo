# TODO App

シンプルで使いやすいタスク管理Webアプリケーションです。バニラJavaScript（フレームワーク不要）で作成され、LocalStorageでデータを永続化します。

## 特徴

- **基本的なタスク管理**
  - タスクの追加、編集、削除
  - タスクの完了/未完了の切り替え
  - タスクの詳細説明

- **高度な機能**
  - カテゴリ/タグによるタスク分類
  - 優先度設定（高/中/低）
  - 期限設定と期限超過の警告
  - タスクの検索機能

- **フィルタリングとソート**
  - ステータス別フィルタ（全て/進行中/完了）
  - カテゴリ別フィルタ
  - 優先度別フィルタ
  - 複数のソートオプション（作成日、期限、優先度、タイトル）

- **データ管理**
  - JSONファイルへのエクスポート
  - JSONファイルからのインポート
  - 完了済みタスクの一括削除
  - LocalStorageによる自動保存

- **レスポンシブデザイン**
  - モバイル、タブレット、デスクトップに対応
  - モダンで直感的なUI
  - ダークモード対応（システム設定に従う）

## 使い方

### アプリケーションの起動

1. リポジトリをクローンまたはダウンロード
2. `index.html` をブラウザで開く
3. すぐに使い始められます（サーバー不要）

### 基本操作

#### タスクの追加
1. 画面上部の「+ Add Task」ボタンをクリック
2. タスクのタイトル（必須）を入力
3. 必要に応じて説明、カテゴリ、優先度、期限を設定
4. 「Add Task」ボタンをクリック

#### タスクの編集
- タスクのタイトルをクリック、または編集アイコン（✏️）をクリック
- 必要な変更を行い「Update Task」をクリック

#### タスクの完了
- タスクカードのチェックボックスをクリック
- 完了したタスクはグレーアウトされます

#### タスクの削除
- 削除アイコン（🗑️）をクリック
- 確認ダイアログで「OK」を選択

#### フィルタリング
- **ステータス**: All / Active / Completed ボタンで切り替え
- **カテゴリ**: カテゴリドロップダウンで選択
- **優先度**: 優先度ドロップダウンで選択
- **検索**: 検索ボックスにキーワードを入力

#### ソート
- ソートドロップダウンで並び順を選択
  - Created Date: 作成日順
  - Due Date: 期限順
  - Priority: 優先度順
  - Title: タイトル順

### キーボードショートカット

- `Ctrl + N` / `Cmd + N`: 新しいタスクを追加
- `Ctrl + F` / `Cmd + F`: 検索にフォーカス
- `Esc`: モーダルを閉じる

### データの管理

#### エクスポート
1. フッターの「Export Data」ボタンをクリック
2. JSONファイルがダウンロードされます
3. バックアップとして保存可能

#### インポート
1. フッターの「Import Data」ボタンをクリック
2. 以前エクスポートしたJSONファイルを選択
3. データが復元されます

#### 完了済みタスクのクリア
1. フッターの「Clear Completed」ボタンをクリック
2. 確認ダイアログで「OK」を選択
3. 完了済みのタスクがすべて削除されます

## データモデル

### タスクオブジェクト

```javascript
{
  id: "unique-id",              // 一意のID
  title: "タスクのタイトル",     // タスク名（必須）
  description: "詳細説明",       // 詳細（オプション）
  category: "work",              // カテゴリ
  priority: "medium",            // 優先度: "high", "medium", "low"
  dueDate: "2026-01-15",        // 期限（ISO形式）
  completed: false,              // 完了状態
  createdAt: "2026-01-11T...",  // 作成日時
  completedAt: null              // 完了日時
}
```

## カスタマイズ

### カテゴリの追加
1. タスク追加/編集モーダルで、カテゴリ選択の横の「+」ボタンをクリック
2. 新しいカテゴリ名を入力
3. カテゴリが追加され、すぐに使用可能になります

### 色やスタイルの変更
- `css/styles.css` の `:root` セクションでCSS変数を編集
- カラースキーム、スペーシング、ボーダー半径などをカスタマイズ可能

## 制限事項

- **LocalStorage容量**: ブラウザの制限により約5-10MBまで
- **オフライン専用**: サーバー同期機能なし
- **単一デバイス**: データは使用中のブラウザにのみ保存されます

## トラブルシューティング

### データが保存されない
- ブラウザのプライベートモード/シークレットモードを使用していないか確認
- LocalStorageが有効になっているか確認
- 容量制限に達していないか確認

### インポートが失敗する
- JSONファイルの形式が正しいか確認
- このアプリからエクスポートしたファイルを使用しているか確認

### パフォーマンスが遅い
- 完了済みタスクをクリアして、タスク数を減らす
- ブラウザのキャッシュをクリア

## 開発者向け

### デバッグ

ブラウザのコンソールで以下のコマンドを使用できます:

```javascript
// アプリケーションオブジェクトにアクセス
TodoApp

// すべてのタスクを取得
Storage.getAllTasks()

// ストレージ情報を取得
Storage.getStorageInfo()

// フィルタされたタスクを取得
TodoApp.getFilteredTasks()

// タスク統計を取得
Task.getStatistics(Storage.getAllTasks())
```
